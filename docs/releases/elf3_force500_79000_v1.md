## Resume／同配方微调

安装与登录SwanLab的方法见主README。在仓库根目录执行：

```bash
./elf3.sh scripts/train_elf3_force500.py \
  --headless --device cuda:0 --num-envs 16384 --seed 42 \
  --iterations 100001 --resume pretrained/model_79000.pt \
  --run-name force500_resume79000_seed42 \
  --swanlab-project DWAQ
```

以上从79001训练到100000，新增21000次更新，每500轮保存。
`--iterations 100001`是总目标更新数，不是再训练100001轮。
省略`--swanlab-project`则只保留本地TensorBoard；每次调用使用新日志目录和可选的新run，
不会覆盖下载的父权重，也不会自动接入原作者的云端记录。

严格续训保持环境数、网络／CENet、PPO、奖励和资产合约一致。恢复网络、Adam、
学习率及轮次，但不恢复仿真物理状态、地形课程等级、随机数流、历史和滤波缓存。
因此可继续优化已有策略，但不是逐步完全一致的现场恢复。

若要改奖励、动作尺度、PD或其他受校验配置，应创建独立任务并显式迁移；
不要绕过合约校验后声称是本模型的同配方resume。这里的“微调”指在固定500 N配方下继续训练。

## 训练来源与使用边界

模型实际经历：原始still_v2 → 踝部成本 → 高度／足力强化 → 动作平滑及峰值采样 →
76500后将足力起罚阈值400提高到500 N，最终在79000保存。
中间含400 N阶段，不等同于公开课程版从零训练的产物。
