# ELF3 DWAQ GitHub 改进版存档（2026-09-22）

本存档基于 GitHub `JKYovo/DWAQ` 的 `main` 提交 `7b584a7`。本地 Git 标签为
`elf3-dwaq-github-improved-20260922`。它记录当前训练代码，不包含权重，且未推送到 GitHub。

## 相对 GitHub 基线的改进

1. 注册 `elf3_dwaq_upper_symmetry_pose_delay`，沿用 ELF3 上身镜像与软姿态任务，
   每个环境在重置时独立抽取 0、20 或 40 ms 动作延迟。
2. 动作进入延迟缓冲区前，按现有 `clip_actions=100` 限幅；缓冲区和实际控制目标
   看到一致的有界动作。此前延迟缓冲区可能保留远大于控制上限的原始动作，
   干扰动作变化率奖励及历史观测，严重时导致训练数值发散。
3. 当前 ELF3 镜像 + 软姿态任务的初始学习率恢复 `1e-3`，自适应范围保持
   `1e-5` 到 `1e-2`。续训加载保存点时仍恢复优化器状态中的实际学习率。

这些修改没有改变 ELF3 资产、关节权重、动作缩放、PPO/VAE 网络结构或上游 G1 任务。
